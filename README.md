# Head over Heels for GFOS

Head over Heels (dougmencken's free remake) for GFOS on amigaallegro (Allegro 5 over SDL2.module / GL.module / OpenGPU).

## Status

Work is on branch `team3/headoverheels-port-20261117` (open draft PR #1).

- Build script, source list, host tests and Part installer are in place.

`main` currently holds only the repo guard; the port itself is on the branch above.
